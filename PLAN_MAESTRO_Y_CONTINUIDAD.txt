W FILE MANAGER — PLAN MAESTRO Y CONTINUIDAD
================================================

REPOSITORIO
https://github.com/wair0/W-FILE-MANAGER
Rama principal: main

OBJETIVO
Construir un gestor de archivos Android fiable, con interfaz HTML/CSS/GLSL y motor funcional Kotlin. JavaScript coordina las interacciones de la interfaz y llama a una API nativa pequeña y controlada.

ARQUITECTURA OBLIGATORIA
- HTML: estructura y contenido de las pantallas.
- CSS: diseño adaptable, componentes, iconos CSS/SVG cuando proceda, temas, estados y animaciones.
- GLSL/WebGL: efectos gráficos opcionales; deben tener degradación elegante si WebGL no está disponible y respetar reducir movimiento.
- JavaScript: navegación visual, renderizado de resultados y comunicación con Kotlin.
- Kotlin: lógica de negocio, acceso al sistema de archivos, permisos, operaciones destructivas, ZIP, cifrado, persistencia y APIs Android.
- WebView: presenta recursos web empaquetados en la aplicación. No usar Jetpack Compose para construir la interfaz.
- Seguridad: mantener el contenido web local; no habilitar acceso arbitrario a archivos para JavaScript; no exponer métodos nativos genéricos; validar parámetros en Kotlin. Añadir solo métodos @JavascriptInterface específicos y necesarios.

REGLAS DE TRABAJO
1. Trabajar directamente en este repositorio; no sustituir los cambios del repo por un ZIP enviado al usuario.
2. Mantener commits pequeños: 1–2 commits por fase. Mensajes claros en español mayúsculas o con prefijos feat/fix/docs.
3. Antes de cada commit, inspeccionar la versión actual de los archivos y el HEAD de main.
4. No afirmar que compila o que una función está terminada sin verificación real.
5. Una fase solo está completa cuando se cumplen sus criterios de salida.
